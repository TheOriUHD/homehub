# Build recipe

Go **1.26.6**, standard library only. `src/go.mod` declares no requirements and
there is **no `go.sum`**, because there are no dependencies to check sums for.
That is deliberate: this binary goes on the machine that fronts all your traffic,
and a dependency tree there is a supply chain you did not ask for.

## Release build — three targets

```bash
VERSION="1.0.0"
LDFLAGS="-s -w -X main.Version=${VERSION}"

CGO_ENABLED=0 GOOS=linux GOARCH=amd64          go build -trimpath -ldflags "$LDFLAGS" -o dist/caddy-reader-linux-amd64 .
CGO_ENABLED=0 GOOS=linux GOARCH=arm64          go build -trimpath -ldflags "$LDFLAGS" -o dist/caddy-reader-linux-arm64 .
CGO_ENABLED=0 GOOS=linux GOARCH=arm   GOARM=7  go build -trimpath -ldflags "$LDFLAGS" -o dist/caddy-reader-linux-armv7 .

( cd dist && sha256sum caddy-reader-linux-* > SHA256SUMS )
```

`src/build.sh release` does exactly this and runs `go vet ./...` and
`go test ./...` first. `src/build.sh` with no argument builds only for the
current machine, to `./caddy-reader`.

### Why each flag

| Flag | Reason |
|---|---|
| `CGO_ENABLED=0` | No libc to match. One binary runs on any Linux of that architecture — Debian, Alpine, a Synology, a Raspberry Pi. This is the whole point of shipping a binary rather than a script whose interpreter you must also keep working. |
| `-trimpath` | Removes build-machine paths from the binary. Reproducible, and it does not leak your directory layout to whoever runs it. |
| `-s -w` | Strips the symbol table and DWARF. Roughly halves the size; there is no debugger on the target anyway. |
| `-X main.Version=…` | The **only** build-time injection. See below. |
| `GOARM=7` | Required for the `armv7` target. Without it Go defaults to `GOARM=7` on most toolchains but not all, and an armv6 binary on a Pi 3 is a silent performance loss. State it. |

### The three targets, and why only three

| Output name | `GOOS/GOARCH` | Typical hardware |
|---|---|---|
| `caddy-reader-linux-amd64` | `linux/amd64` | ordinary servers, VMs, NUCs |
| `caddy-reader-linux-arm64` | `linux/arm64` | Pi 4/5 on 64-bit OS, ARM VPS, Apple-silicon VMs |
| `caddy-reader-linux-armv7` | `linux/arm` + `GOARM=7` | Pi 2/3 and 32-bit Pi OS |

`install.sh` maps `uname -m` onto exactly these three names:

```
x86_64  | amd64  → amd64
aarch64 | arm64  → arm64
armv7l  | armv7  → armv7
```

Anything else exits with *"No build for `<arch>`. Build from source."* Adding a
target means adding a `build` line **and** a `uname -m` case, or the installer
will not know to ask for it.

## Version stamping

```go
// main.go
var Version = "dev"
```

`-X main.Version=1.0.0` overwrites it at link time. An unstamped build reports
`dev`, which is a useful signal rather than a bug: it means someone built it by
hand.

`src/VERSION` holds the canonical string and `build.sh` reads it, so the tag, the
binary and `caddy-reader version` agree without anyone remembering to update
three places.

> **No secret is embedded at build time.** `main.Version` is the only `-X`, and
> it is a version string. The bearer token is generated by `crypto/rand` on the
> target machine during `caddy-reader setup` and written to
> `/etc/caddy-reader.env` (mode `0600`). It never touches the build, the binary,
> or any file in this export.

## Checksums

`build.sh release` writes `dist/SHA256SUMS` covering all three binaries, so
someone downloading one for their reverse proxy can verify they got what was
built. Serve it alongside them (see `serve/URL-PATHS.md`).

## Verifying a build before shipping it

```bash
cd src
go vet ./...
go test ./...          # caddyfile_test.go, projection_test.go
./build.sh release
file dist/caddy-reader-linux-amd64     # → "statically linked"
dist/caddy-reader-linux-amd64 version  # → 1.0.0
```

`file` reporting **statically linked** is the check that matters. If it says
"dynamically linked", `CGO_ENABLED=0` did not take effect and the binary will
fail on a machine with a different libc — which is exactly the failure this build
recipe exists to prevent, and it will not show up until someone installs it on an
Alpine box.
